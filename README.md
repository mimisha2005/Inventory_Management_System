# Inventory Management System

A console-based Inventory Management System developed using **Java** and **Object-Oriented Programming (OOP)** concepts. The application allows users to manage products and perform basic inventory and stock-related operations through a command-line interface.

## Features

* Add and manage products
* Add stock to existing products
* Reduce stock based on inventory operations
* Display product and inventory information
* Validate stock quantities and user input
* Handle invalid operations using exception handling

## Technologies Used

* **Language:** Java
* **Concepts:** Object-Oriented Programming, Collections, Exception Handling
* **Collections:** ArrayList, HashMap
* **Development Environment:** VS Code

## OOP Concepts Implemented

The project demonstrates the following Object-Oriented Programming concepts:

* **Encapsulation** – Organizing data and related methods within classes
* **Inheritance** – Reusing common properties and behavior through class relationships
* **Polymorphism** – Implementing different behaviors through method overriding
* **Abstraction** – Using abstract classes to define common functionality

## Data Structures

### ArrayList

Used for storing and managing collections of objects where sequential access and dynamic sizing are required.

### HashMap

Used for storing products using key-value pairs, allowing products to be accessed efficiently using their identifiers.

## Exception Handling

The application uses Java exception handling to manage invalid operations and user input.

For example, stock operations validate that the quantity being added or removed is positive before modifying the inventory.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/mimisha2005/Inventory_Management_System.git
```

### 2. Open the project

Open the project folder in **VS Code** or another Java-supported IDE.

### 3. Compile the Java files

From the project directory, compile the required Java source files:

```bash
javac *.java
```

### 4. Run the application

```bash
java Main
```

Follow the instructions displayed in the console.
